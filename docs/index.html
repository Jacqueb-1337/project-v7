Project V7

An Android APK patcher and compatibility project for running supported older 32-bit ARMv7 and armeabi-v7a apps and games on newer 64-bit-only Android devices.

Experimental: Cops N Robbers is the only officially supported game

Project V7 is still experimental. Cops N Robbers 3.0.2 is the only officially supported game.

Project V7 is designed around 32-bit Unity 4.x-era games, with Unity 4.6 Mono as the current tested baseline. Other games from that era may work in theory, but they are untested. Significant runtime and compatibility work remains, and other engines need additional backends.

Android 32-bit compatibility on 64-bit-only phones

Many older Android apps and games ship only 32-bit native code. Newer Android devices may no longer provide native 32-bit app support. Project V7 provides an app-specific compatibility path for supported software instead of requiring an old Android device or a full virtual machine.

Project V7 primarily targets older ARMv7 and armeabi-v7a Unity 4.x-era Android games. Unity 4.6 Mono is its tested starting point; games with different Unity versions, native libraries, APK layouts, or engine behavior may require further compatibility work. Support is profile-based, allowing fixes to be developed per app without hard-coding every game into the patcher.

How Project V7 works

For apps that need it, Project V7 builds a 64-bit host around the original 32-bit app and applies compatibility modules for the app, its engine, and Android behavior it expects. The patcher reads its supported-app catalog and compatibility profiles from the Project V7 repository.

Cops N Robbers 3.0.2

Cops N Robbers 3.0.2 is Project V7's first tested application and its main compatibility test case. The original game is a 32-bit ARMv7 Unity title. Project V7 includes a tested compatibility profile for it.

Frequently asked questions

Can Project V7 run 32-bit Android apps on 64-bit-only phones?

Project V7 currently officially supports only Cops N Robbers 3.0.2. Compatibility with other games is under active development and should be considered experimental, even when an APK can be selected or patched.

Will other Unity 4.x games work?

Possibly. Project V7 was built around a Unity 4.6 Mono game, and other 32-bit Unity games from the same era are promising candidates. They have not been tested or officially supported, and major compatibility work remains. A successful patch does not guarantee that a game will launch or run correctly.

Does Project V7 support ARMv7 and armeabi-v7a?

ARMv7 and armeabi-v7a apps are primary compatibility targets, but compatibility is not universal or automatic.

Is Project V7 a full Android emulator?

No. It uses a 64-bit host and compatibility modules for supported apps instead of emulating an entire Android environment.
