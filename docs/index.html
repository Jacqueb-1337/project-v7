Project V7

An Android APK patcher and compatibility project for running supported older 32-bit ARMv7 and armeabi-v7a apps and games on newer 64-bit-only Android devices.

Download Project V7 View source on GitHub

Android 32-bit compatibility on 64-bit-only phones

Many older Android apps and games ship only 32-bit native code. Newer Android devices may no longer provide native 32-bit app support. Project V7 provides an app-specific compatibility path for supported software instead of requiring an old Android device or a full virtual machine.

Project V7 targets older ARMv7 and armeabi-v7a Android software, including legacy Unity games. Support is profile-based, so compatibility fixes can be added per app without hard-coding every supported title into the patcher.

How Project V7 works

For apps that need it, Project V7 builds a 64-bit host around the original 32-bit app and applies compatibility modules for the app, its engine, and Android behavior it expects. The patcher reads its supported-app catalog and compatibility profiles from the Project V7 repository.

Cops N Robbers 3.0.2

Cops N Robbers 3.0.2 is Project V7's first tested application and its main compatibility test case. The original game is a 32-bit ARMv7 Unity title. Project V7 includes a tested compatibility profile for it.

Frequently asked questions

Can Project V7 run 32-bit Android apps on 64-bit-only phones?

For supported apps, yes. Project V7 provides app-specific compatibility rather than claiming universal support for every 32-bit APK.

Does Project V7 support ARMv7 and armeabi-v7a?

Yes. ARMv7 and armeabi-v7a Android apps are primary compatibility targets.

Is Project V7 a full Android emulator?

No. It uses a 64-bit host and compatibility modules for supported apps instead of emulating an entire Android environment.
